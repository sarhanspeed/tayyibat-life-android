# Changelog

## 2.2.0
- Expanded the bilingual home-workout library with more lower-body, upper-body, core, cardio and mobility exercises.
- Added offline two-frame movement illustrations for exercises plus bilingual movement steps, target muscles, sets/reps/time, rest and caution notes.
- Added more ready-made workout programs including full-body, no-jump, lower-body, upper-body, core, mobility and cardio sessions.
- Expanded the Tayyibat food guide using the publicly available educational Tayyibat food list. Items without a supported classification remain marked for review rather than being guessed.
- Reworked food nutrition references to use generic real-world reference values per 100 g, with common serving weights and gram-based calorie/macronutrient calculation. Actual values can vary by brand, recipe and cooking method.
- Added daily weight logging with date, one editable entry per day, recent trend and history/delete controls.
- Added intermittent-fasting tracker with 12:12, 14:10, 16:8, 18:6, 20:4 and custom schedules, live elapsed/remaining time, start/stop and fasting history.
- Added fasting safety messaging and kept fasting independent from medical treatment or automatic medication advice.
- Improved home dashboard with latest weight, fasting state, food calories, exercise minutes and hydration.
- Preserved Arabic/English interface, light/dark themes, meal editor, meal scanner, barcode scanner and cloud APK build.

Safety/data note: Tayyibat labels are educational system classifications rather than medical diagnoses. Generic nutrition references vary by product/preparation. Exercise calorie burn is estimated. Fasting can require clinician guidance for some users.
