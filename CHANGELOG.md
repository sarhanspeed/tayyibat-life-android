# Changelog

## 2.1.0
- Added a full bilingual Home Workouts section.
- Added exercise library with sets, reps/time, rest, technique and caution notes.
- Added ready-made beginner, low-impact, full-body, core and mobility programs.
- Added smart “Today workout” generation based on preferred level and duration.
- Added custom workout builder.
- Added active workout session, set tracking, timed sets, rest countdown and completion summary.
- Added workout history, streak, minutes and estimated activity calories.
- Added weight log and improved progress dashboard.
- Added water tracker and improved daily dashboard.
- Added food favorites and user photos for foods.
- Added meal photos, improved editable meal builder and meal logging.
- Improved meal photo scanner flow and confirmation workflow.
- Added real ML Kit barcode recognition from the Android camera plus manual product lookup.
- Added local user-created products that are marked as needs review.
- Added light/dark themes and bilingual Arabic/English UI.
- App launcher name is localized in Arabic and English.
- Cloud build remains the source of installable APK artifacts.

Safety note: exercise calorie burn is an estimate. Exercise guidance is general fitness information and is not medical treatment.
